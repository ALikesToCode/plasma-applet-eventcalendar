Plasma Event Calendar

Privacy Policy

Last updated: 2026-11-01

Summary

Plasma Event Calendar is a free, open-source calendar widget for the KDE Plasma desktop. It is maintained by ALikesToCode on GitHub. The widget runs entirely on your computer. It has no server of its own. Your Google data travels only between your computer and Google, and the developer never receives it.

Plasma Event Calendar's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Google Calendar and Google Tasks

The widget does not connect to Google unless you sign in from its settings (Settings > Google Calendar). Signing in opens Google's own sign-in page in your web browser, where Google shows you the access the widget is asking for. You can decline.

Data the widget accesses

  • Your list of calendars: names, colours, time zones and your access level, so you can choose which calendars to show.
  • Events in the calendars you choose, as Google returns them, such as the title, time, location, description, attendees and video call links.
  • Your task lists and the tasks in the lists you choose.

How the widget uses this data

  • To show your events and tasks in the Plasma panel, the calendar popup and the agenda.
  • To make the changes you ask for in the widget: adding, editing or deleting an event, and adding, editing, completing or deleting a task. The widget never changes your data on its own.
  • To refresh this information from time to time, and when you press Refresh.

The widget does not use Google data for advertising. It does not sell it, and it does not use it to develop, improve or train generalized artificial intelligence or machine learning models. No person reads your data.

Where the data is stored

  • Your Google access and refresh tokens, and the client secret if you use your own OAuth client, are stored in your desktop keyring: Secret Service (for example GNOME Keyring or KeePassXC) or KWallet. They are not written to the widget configuration file.
  • An account label, your list of calendars and task lists (IDs, names, colours, time zones and access level) and which of them you chose are stored in the Plasma widget configuration file, ~/.config/plasma-org.kde.plasma.desktop-appletsrc.
  • Events and tasks are kept in memory only while Plasma is running. They are not written to disk, and they are downloaded again when the widget refreshes.

Sharing

All requests go directly from your computer to Google's APIs over HTTPS. The widget does not send Google data to the developer or to anyone else. It does not use analytics or tracking.

Signing in

After you sign in, Google sends a one-time authorization code to a temporary address on your own computer (http://127.0.0.1). The widget exchanges that code with Google for tokens. If you paste a redirect URL into the OAuth helper on this website instead, the code is read by JavaScript in your browser and is not sent to any server run by the developer. This website is hosted by GitHub Pages, which may log visits as described in the GitHub Privacy Statement.

Removing your data and revoking access

  • In the widget, open Settings > Google Calendar, select the account and press Remove. This deletes its tokens from your keyring and its calendar list from the widget configuration. Removing the widget from your panel removes its configuration but leaves the tokens in your keyring, so remove the account first, or delete the keyring entries whose names start with plasma-applet-eventcalendar.
  • To revoke the widget's access on Google's side, go to myaccount.google.com/connections, choose Plasma Event Calendar and remove its access. The widget then stops receiving data until you sign in again.

What the developer can see

The Google Cloud console shows the developer aggregate numbers for the widget's OAuth client: how many API requests were made and how many failed, by API method and HTTP status code. These numbers are totals for all users. They do not include who made a request or any calendar or task content.

Other online services

These features are off by default. When you turn one on, the widget connects directly to that service, which can see your IP address and the request.

  • Weather: if you choose a city, the widget downloads forecasts from OpenWeatherMap (privacy policy) or Environment and Climate Change Canada (weather.gc.ca), depending on the provider you choose.
  • iCalendar feeds: if you add an iCal URL, the widget downloads it from the server that hosts it.

Downloads

If you install the widget from the KDE Store (for example with Get New Widgets in Plasma), the KDE Store privacy policy applies to the download. If you install it from GitHub or the AUR, GitHub's privacy statement applies. The developer can see how many times each release was downloaded, but not who downloaded it.

Changes and contact

If this policy changes, the new version will be published on this page with a new date. Questions and requests can be raised as an issue on GitHub.
